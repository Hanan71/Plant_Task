# 🌱 Plant Task

An interactive mobile application built with **SwiftUI** and the **MVVM** architectural pattern. Plant Task helps users manage plant care reminders, track daily watering progress, and keep their plants healthy and thriving.

## ✨ Features

- **Modern UI:** A sleek dark theme with refined UI components and an interactive progress bar displaying daily watering completion.
- **MVVM Architecture:** Clean separation of concerns between data models (`PlantItem`), business logic (`PlantViewModel`), and UI views.
- **Local Notifications:** Automated reminders using `UserNotifications` to help users stay on top of their plant care schedules.
- **Interactive Plant Management:** Supports swipe-to-delete functionality and a custom modal for adding plants with personalized properties, including room location, light intensity, and water amount.

## 🛠 Tech Stack

| Technology | Description |
|---|---|
| Language | Swift 5.0+ |
| Framework | SwiftUI |
| Architecture | MVVM (Model-View-ViewModel) |
| Frameworks | UserNotifications, Foundation |

## 🚀 Getting Started

Follow these steps to run the project locally on your Mac using Xcode.

### 1. Clone the Repository

```bash
git clone https://github.com/Hanan71/Plant_Task.git
```

### 2. Open the Project

Navigate to the project directory and open the `Plant Task.xcodeproj` file using Xcode.

### 3. Select a Simulator

Choose an available iOS simulator from the Xcode toolbar (e.g., iPhone).

### 4. Build and Run

Click the **Run (▶️)** button in Xcode or use the following keyboard shortcut:

```text
Cmd + R
```

If you encounter cached build issues, clean the build folder first:

```text
Cmd + Shift + K
```

Then build the project:

```text
Cmd + B
```
